# Main-text evidence allocation

| Evidence | Function | Destination | Reason |
|---|---|---|---|
| Three complete-rule passing cells | core discovery | Results main text and primary table | Establishes the bounded claim. |
| Complete eight-cell matrix | qualification and heterogeneity | Primary table plus one Results paragraph | Prevents selective reporting and bounds mechanism/backbone variation. |
| Construct fixture ladder | necessary support | Construct Validation and compact table | Shows metric selectivity before model access. |
| All resolution curves and timing diagnostics | robustness/provenance | Archived artifacts; later supplementary material | Required for completeness but not for the shortest primary evidence chain. |
| Post-primary fitted references | qualification | One Results paragraph and separate table | Contextualizes attainability and mechanism difficulty without entering the primary gate. |
| Config, code, checkpoint, and unit hashes | provenance detail | Experimental Protocol and repository artifacts | Supports reproducibility without interrupting the result narrative. |
| P0 null screening result | motivation only | Introduction/Protocol in one sentence if needed | It motivates a new shape question but is not P1 evidence. |

Shortest main-text evidence chain: construct selectivity $\rightarrow$ complete frozen
matrix $\rightarrow$ three passing cells with forecast-skill complement $\rightarrow$
complete-matrix boundary $\rightarrow$ descriptive fitted-reference context.

Claim-repetition roles: title introduces; Introduction motivates; Results demonstrates;
Discussion interprets; Conclusion synthesizes. Numerical intervals remain authoritative
in tables and archived reports rather than being repeated in every section.
