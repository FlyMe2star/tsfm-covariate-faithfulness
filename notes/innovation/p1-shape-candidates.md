# P1-SHAPE candidate-framing decision

## A. Multi-resolution response-shape audit — selected

- **Claim:** Coarse correctness in direction and total gain can coexist with incorrect
  onset, peak, duration, rebound, or interaction shape.
- **Evidence:** Untouched paired structural mechanisms, signed shape distance at widths
  1/2/4/8, frozen checkpoints, transparent references, and series-cluster intervals.
- **Falsifier:** The frozen cell-count, diversity, or accuracy-complement rule fails.
- **Selection reason:** It is adjacent to P0 without reinterpreting P0 and remains
  distinct from scalar generator-parameter interventions and counterfactual generation.

## B. Intervention-resolution robustness curve — retained as analysis

- **Claim:** Shorter or more localized interventions are harder for TSFMs to transmit.
- **Risk:** Without structural shape metrics this resembles a standard perturbation
  stress test.
- **Decision:** Intervention width is a frozen stratum, not the core novelty claim.

## C. Functional equivariance testing — retained as construct validation

- **Claim:** Valid response operators should obey selected scaling, temporal-shift, and
  superposition relations.
- **Strength:** Produces clean metamorphic fixtures and catches implementation errors.
- **Risk:** Full equivariance is not warranted for nonlinear or state-dependent DGPs.
- **Decision:** Use only where each structural mechanism analytically licenses the
  relation; do not make a universal model claim.

## D. Counterfactual-input generator — rejected

ForecastCF, CounTS, CET-X, and related work already make counterfactual generation a
crowded area. It also changes the research object from auditing a model response to
optimizing an input path.

## E. Learned safeguard or calibration — deferred

A safeguard before a verified P1 failure would create result-driven method search and
repeat the earlier project risk. It requires a separately approved contract and
untouched confirmation evidence after P1.
